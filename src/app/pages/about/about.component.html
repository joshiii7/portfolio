How I work

I'm a full-stack software developer who builds web applications, mobile applications, and desktop software for organizations that need technology built around how they actually work, not the other way around.

My background is in design, so usability and functionality are never an afterthought. What I enjoy most is taking a manual, time-consuming process, like permit processing, inventory tracking, or payroll computation, and turning it into something faster, more reliable, and easier for people to actually use every day.

I hold a Computer Science foundation and a national-level certification in web development (TESDA NC III). Whatever the project, I aim for the same thing: software that's reliable, easy to use, and solves the actual problem it was built to solve.
